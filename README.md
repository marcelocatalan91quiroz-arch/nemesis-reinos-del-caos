# NÉMESIS: REINOS DEL CAOS

Juego de cartas estratégico construido desde cero.

## Reglas de desarrollo

- `main` debe permanecer estable.
- Todo cambio funcional se desarrolla en una rama `feature/*` o `fix/*`.
- Ningún cambio entra a `main` sin pruebas automáticas.
- No se reutiliza código del proyecto NÉMESIS anterior.
- No se despliega a Vercel durante el desarrollo inicial.
- Las rutas se definen una sola vez y se validan automáticamente.
- Cada carta tendrá un ID de definición estable y cada instancia de duelo un UID único.
